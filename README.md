# Laboratorio

A Spanish reading lab for the browser: Latin American Spanish passages with every word tappable, flip cards with English respellings, a spelling trainer, spoken Spanish from your device's own voices, daily goals and progress, and optional sync through a private GitHub repository.

**Open it:** https://huss234.github.io/laboratorio/

- Everything is in one file, `index.html`. No build step, no dependencies.
- Lessons come from any AI assistant: Settings → Add lessons has a paragraph prompt and a deck prompt. Paste one with your Spanish under it, then import the JSON reply.
- Your library stays in the browser. Sync is optional and goes only to your own private repository (default `laboratorio-data`).
- `DESIGN.md` is the design standard for every screen; `CLAUDE.md` holds the house rules.

Laboratorio is the Spanish sibling of [Sprachlabor](https://huss234.github.io/sprachlabor/). The two apps keep separate storage and never read each other's data.
